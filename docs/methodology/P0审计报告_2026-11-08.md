## 三、已确认缺陷（7 项）

### D1 年化分母用 252，而 A 股每年只有 242.85 个交易日 ★最重要

**现象**：`met()` 用 `y = nav.length / 252` 换算年数。

**证据**：

```text
交易日 4,089 ｜ 日历跨度 16.8378 年 ｜ 实测 242.85 交易日/年
252 口径年数 16.2262  →  少算 0.61 年（−3.63%）
```

**影响**：所有年化收益**系统性高估 0.11~0.14pp**。

| 档位 | 已发布（252 口径） | 日历年化（正确） | 差 |
| :--- | ---: | ---: | ---: |
| R=15% / E=25% | 3.078% | 2.965% | −0.113pp |
| **R=20% / E=35%** | **3.327%** | **3.204%** | **−0.123pp** |
| R=25% / E=45% | 3.526% | 3.396% | −0.130pp |
| R=30% / E=55% | 3.676% | 3.541% | −0.136pp |
| v1.5 主口径 R=20% / E=40% | 3.433% | 3.306% | −0.127pp |

**为什么这件事比看上去严重**：v1.6 用「年化代价约 0.1pp」来论证把 E 从 40% 降到 35% 是划算的。而年化口径本身的偏差是 **0.123pp——比它论证的那个代价还大**。两者不冲突（一个是相对选择、一个是绝对水平），但意味着：**在 v1.6 里，「0.1pp/年」这个量级的比较已经处在口径精度的边缘。**

**处置**：**不改引擎默认值**。理由是改它会作废已发布的全部年化数字，而 MDD 一个都不变、没有任何决策会翻转。采取「并列披露」：

- 所有报告中的年化数字旁标注 `252 口径`；
- 需要绝对水平时用日历年化值；
- **做差值比较（v1.5 vs v1.6、策略 vs 基准）时，只要两边同口径，结论不受影响** —— 差值的变化只有 0.004~0.007pp。

已写入 `data_audit.js` 检查项 9、`regression_baseline.json` 的 `cagrCal` 字段、`test_regression.js` 的双口径输出。

### D2 股息率序列存在插值前视（量级小，但性质是前视）

**现象**：`valuation_series.js` 的 `interp()` 在观测点 a、b 之间做线性插值，而 b 是 a 之后最多半年才可得的数据。因此区间内每一天的股息率都用到了未来信息。

**证据**：34 个半年度观测点，受影响交易日 4,088 / 4,088，与「仅用已发生观测」的阶梯序列最大偏离 **2.154pp**（红利）、0.961pp（沪深300）。

**影响**（实测，E=35%）：

| 股息率口径 | CAGR（252 口径） | MDD |
| :--- | ---: | ---: |
| 现行（线性插值） | 3.327% | 17.234% |
| 无前视（阶梯） | 3.321% | **17.291%** |

CAGR −0.006pp、MDD +0.057pp。四档 MDD 分别 +0.044 / +0.057 / +0.068 / +0.077pp，**余量全部仍 > 2.7pp**（最薄的 R=20% 档从 2.766pp 降到 2.709pp，只多出 0.009pp）。

**处置**：已提供 `interpStep()` 与 `dyHS_nl / dyHL_nl`，并把「切换正式口径」排在下一版。本轮不切，理由同上：影响量级 0.006pp，低于任何决策相关精度，切换会作废全部已发布数字。**审计已把它标为 WARN，不再算「没人知道」。**

> 注：R=20%/E=35% 的余量 2.709pp 距阈值 2.7pp 只差 0.009pp。这说明 **2.7pp 这条线是「刚好卡住」的，不是「宽松通过」的**。若下一版切换无前视口径，这一档就处在临界。

### D3 触发阈值比较无容差

**现象**：`if (dd >= rc.R)`。`dd = 1 − nav/V`，十进制下几乎不可能恰好等于 R，`>=` 会**漏判「正好触及」这个最需要触发的临界点**。

**这与纸面台账工具里已修过的缺陷是同一类**（`1 − 400000/500000 = 0.19999999999999996`）。台账修了，引擎没修——不一致本身就是缺陷。

**处置**：已改为 `dd >= rc.R - 1e-9`（`TRIGGER_EPS`）。**数值影响：0**（主口径余量 0.309pp，无单元落在 1e-9 内）。

### D4 两序列按索引对齐，但无守卫

**现象**：全仓库按索引访问两个序列（`rD(i) = D[i]/D[i-1]`），却没有任何行数/日期一致性检查。一旦数据文件被换版本、少一行，**所有收益、回撤、再平衡会静默错位且不抛错**。

**实测**：当前数据完全对齐（错位 0 行）。但这是"碰巧对"，不是"保证对"。

**处置**：`phase2_indices.js` 加载即校验，不一致直接 `throw`，并提示先跑 `node data_audit.js`。

### D5 初始建仓未计交易成本

**现象**：`runRClause` 第 363 行按目标权重直接建仓，未收 5bp 手续费 + 10bp 滑点。

**影响**：一次性少计约 `35% × 15bp ≈ 0.05%`，折年约 0.003pp。**量级可忽略，但确实是一笔漏掉的成本。**

**处置**：不改基线（会作废净值），在报告中披露；`execution_simulator.js` 的实盘口径**计入**这笔成本。

### D6 同日「减半」与「季度再平衡」双重重置

**现象**：若触发日的前一日恰是季末（挂起了 `pendingRebal`），次日先执行 `pendingCut`，随后 `else if (pendingRebal)` 又执行一次 `doReset`。第二次重置会把权重再压到 `(t−cost)×eqTarget`，产生**虚假成交与虚假成本**，且 `rebalCount` 多计一次。

**处置**：已改为「减半已含重置，取消同日重复挂单」，新增计数器 `supersededRebal`。**数值影响：0**（主口径触发 0 次，不经过该分支）。

### D7 价格数据无溯源

**现象**：`hs300_daily_2010_2026.json` / `csi_dividend_2010_2026.json` 只有 `data.klines`，**没有 source、下载时间、复权口径、供应商版本**。估值文件有（`NeoData index_valuation`，2026-11-07）。

**处置**：新增 `data_manifest.json`，记录三份文件的 **sha256 + 字节数 + 生成时间**。任何一份被替换，`test_regression.js` 会直接报「数据文件已变，净值基线可能不再适用」。`source/fetched/复权口径` 三个字段需要你确认后人工补写——**我不替你填，因为我不知道这批数据的真实出处**。

## 四、三项新增证据（回应审阅意见的策略层质疑）

### E1 「25% 红利承担防御职能」在全样本上不成立 ★动摇立论

审阅意见提出「中证红利不是独立于沪深300 的防御资产」。**实测支持这个质疑，而且比它说的更彻底。**

纯权益（eq=100%，季度再平衡，含成本）：

| 红利权重 | 全程 CAGR | 全程 MDD |
| ---: | ---: | ---: |
| 0%（纯沪深300） | 2.59% | 46.27% |
| 25%（现行） | 3.59% | 45.94% |
| 50% | 4.53% | 45.82% |
| 100% | 6.23% | 45.66% |

**红利从 0% 加到 100%，最大回撤只从 46.27% 降到 45.66%——降了 0.61pp，等于没有。** 而年化涨了 3.64pp。

子区间一拆，原因就出来了：

| 区间 | 0% 红利 MDD | 25% 红利 MDD | 100% 红利 MDD |
| :--- | ---: | ---: | ---: |
| 2010-01 ~ 2019-01 | 46.27% | 45.94% | 45.66% |
| 2019-01 ~ 2026-11 | 42.26% | **30.09%** | **21.33%** |

**全样本 MDD 由 2015 年那一次共同崩盘决定，那时候两者一起跌，红利没有任何防御作用。** 防御性只在 2019-2026 出现，因为那段是「沪深300 熊、红利牛」的风格分化——**这是某一次风格轮动的结果，不是资产的结构属性。**

**结论**：

- 「红利提高收益」——样本内成立（每 +25% 约 +1.0pp/年），但这是**单一因子周期**的结果，不能外推。
- 「红利降低回撤」——**全样本不成立，连普通回撤都不降，更谈不上尾部保护。**
- **但也不能反过来把权重改到 50% 或 100%**。那等于用同一段样本里的因子表现去赌下个十年，正是这个项目一路在反对的事。

**需要澄清一处措辞**：v1.6 §2 的研究注释已经写了「**25% 不承担尾部保护职能**」，这句话是对的，本审计不推翻它。但它只否掉了「尾部保护」这一项，没有否掉「降低回撤」——而实测表明后者同样不成立。**当年用「有倾斜优于无倾斜」支持 25% 时，那个「优」全部来自收益端，风险端是零。** 所以 25% 仍然可以保留，但支撑它的应该是「不押注单一因子 + 因子周期不可预测 + 主动上限便于执行」，而不是任何形式的「更稳」。

这一条是**判断**，不是错误：改不改 v1.6 正文的措辞由你定。本报告只提供数字。

### E2 「季度再平衡是慢熊中的风险放大器」——方向对，量级小，且全样本反向

审阅意见提出五个对照组。跑完（eq=35%，R 条款关闭）：

| 再平衡间隔 | 约频率 | CAGR（日历年化） | MDD | 次数 |
| :--- | :--- | ---: | ---: | ---: |
| 63 日（**现行**） | 3.85 次/年 | **3.204%** | **17.234%** | 64 |
| 126 日 | 1.93 次/年 | 3.104% | 19.396% | 32 |
| 252 日 | 0.96 次/年 | 3.142% | 19.003% | 16 |
| 504 日 | 0.48 次/年 | 3.026% | 25.658% | 8 |
| 从不再平衡 | — | 2.540% | 18.011% | 0 |

**全样本上季度再平衡的 MDD 最低（17.234%），不是最高。** 因为它在 2015 崩盘前就不断把涨上来的权益卖回落袋。

再看段内：

| 情景 | 63 日 MDD | 252 日 MDD | 63 日收益 | 252 日收益 |
| :--- | ---: | ---: | ---: | ---: |
| 2015 股灾 | 16.05% | **15.15%** | −20.75% | −19.66% |
| **慢熊 2021-02~2024-09** | **9.33%** | **8.52%** | −2.32% | −2.17% |
| 急跌 2024-05~09 | 4.95% | 4.80% | −14.79% | −14.35% |

**在慢熊段内，季度再平衡确实更差：MDD 差 +0.81pp、收益差 0.15pp/年。机制成立。** 但量级不足以改变任何结论，且全样本上被反向效应盖过。

**结论**：「季度再平衡是慢熊放大器」——**段内成立、全样本不成立**。不改规则；把这个双面性写进已知局限，比单方面宣称「季度最优」或「季度有害」都更接近事实。

> 审阅意见提的「偏离阈值再平衡」「只允许降低权益的非对称再平衡」没有实现——那是**新增机制**，不是参数扫描。按项目一贯原则（不堆砌规则），登记为未检验，不写进策略。

### E3 整手约束与最低佣金：50 万元账户下可忽略

审阅意见担心「50 万该买多少份、最小交易单位怎么处理」。新建 `execution_simulator.js` 实测（35% 权益 / 75:25 / 季末再平衡，全程 16.8 年）：

| 5 万 | 3.17% | 17.58% | 0.72% | 0.63% |
| 10 万 | 3.17% | 17.66% | 0.47% | 0.56% |

| 100 万 | 3.201% | 17.253% | 0.071% | 0.068% |

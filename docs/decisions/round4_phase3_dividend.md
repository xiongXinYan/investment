## 一、【任务 1 · 本轮核心】压力路径 A/B/C 下股息现金流建模的合理性

### 1.1 现有引擎股息建模：一个必须写清的恒等式

【事实·高】`bt_final.js:48-57` 逐行内容：

```js
uD = eq·w / D[S].c;  uH = eq·(1−w) / A[S].c;   // uD=中证红利份额, uH=沪深300份额
vD = uD·D[i].c;      vH = uH·A[i].c;           // 当日市值
divCash = (vD·dyDAt(i) + vH·dyHAt(i)) / 252;  // dyD=红利股息率, dyH=HS300股息率
tax     = divCash · o.divTax;                  // ← 固定比例税，无期限、无清算
cash   += divCash − tax − e2·FEE_ANN/252;
cash   *= 1 + rateAt(i)/252;
```

【推断·高】**核心恒等式**：股息率的定义是 `dy = DPS / P`，而市值 `v = u · P`（u 为份额）。故

> `v · dy = (u · P) · (DPS / P) = u · DPS`

即 **「市值 × 股息率」恒等于「份额 × 每股股息」，与价格 P 无关**。这一恒等式是判断合成路径自洽性的唯一标尺：

- 在**真实历史序列**里，`dyHL[i]` 由 NeoData 半年度观测点（本身用当时真实价格 P(t) 计算）线性插值而来，`v·dy ≈ u·DPS`，**自洽**。
- 在**合成压力路径**里，价格被人为替换为 `P^synth`，但 `dy` 仍沿用历史插值 `dy^hist` → 隐含每股股息 `DPS^implied = P^synth · dy^hist`，**即 DPS 被隐式设定为随合成股价同比例变动**。

（来源：`bt_final.js`、`valuation_series.js`、`valuation_semiannual_2010_2026.json`；本地重算 2026-11-07。）

### 1.2 机制问题 ①：价格大跌时股息率会机械抬升 —— 「分红基数下移」会被双重扣减

【推断·高】设 A 路径权益累计跌幅为 R 的 2.0~2.5 倍（R=20% → 40~50% 量级，Phase 2 §六参数表，【判断·低】情景假设）。三种可选口径给出**三条完全不同的 divCash 路径**：

| 口径 | dy 的处理 | divCash 随价格下跌 | 隐含假设 |
| :--- | :--- | :--- | :--- |
| **(a) 现有引擎**：沿用历史插值 `dy^hist` | 外生、与合成价格脱钩 | **随市值线性缩水 40~50%** | 隐含 `DPS` 与股价**同比例**下跌（分红基数下移幅度 = 股价跌幅） |
| **(b) 分母效应正确建入**：`dy^synth = DPS^fixed / P^synth` | dy 随价格下跌机械**抬升**（腰斩则翻倍） | **恒定不变**（`= u·DPS^fixed`） | DPS 短期黏性、不随股价变；符合分红由盈利/派息政策决定的常识 |
| **(c) 显式分红削减**：另设 DPS 路径 `DPS(t)` 下移 | 由 `DPS(t)/P^synth(t)` 内生决定 | 按 DPS 削减幅度下降 | 企业盈利与派息率下移，有滞后 |

**两个机制问题由表直接读出**：

1. **口径 (a) 无经济依据且与「分红黏性」相反**【判断·中】：DPS 由上一年度盈利、派息政策与董事会/股东大会决议决定，年度宣布、次年实施，短期内对股价近乎无弹性。让 DPS 跟着股价腰斩，等于把「估值波动」当成「分红能力波动」。更严重的是，它**低估了下跌途中的股息 carry**（现金端缓冲被人为削薄）→ 回撤被系统性高估 → **R 更易被判触发**。
2. **若同时按「分红基数下移」再显式削减一次 DPS，就是双重扣减**【推断·高】：一次已经隐含在「价格 → 市值 → divCash」链路里，一次来自显式 DPS 路径，两者叠加会把 carry 压到不合理解。反过来，若改按 (b) 处理「分母效应」、同时又把 `dy^hist` 原样套上，也会出现 `dy` 同时被「抬升」与「历史给定」两个规则争用的自相矛盾。
   > **正确处置**：**DPS 路径与价格路径必须分离**。divCash 应以 `u · DPS(t)` 计算，或等价地令 `dy(t) = DPS(t)/P(t)` 动态重算；**禁止**把历史插值 `dy^hist` 直接乘到合成价格生成的市值上。

3. **股息率上限/下限必须显式设**【判断·中】：若采用 (b)，A 路径 40~50% 跌幅会把红利股息率从起点 4.10% 机械抬到约 **6.8~8.2%**（`4.10%/(1−0.4~0.5)`，【推断·中】解析近似），**已超出本地 34 观测点全期最大值 6.5343%**（2022-12-30，【事实·高】）。这不是错误，但必须标注「该抬升是纯分母效应、非分红能力改善」，并用 `dy ∈ [1.2297%, 6.5343%]`（本地 34 点全期极值，【事实·高】）作为**诊断带**而非硬裁剪依据，避免下游把机械抬升误读为「高股息更具吸引力」的信号。

### 1.3 机制问题 ②：慢熊 / 通缩情景下，股息率是升是降 —— 方向不定且路径依赖

【推断·中】`dy = (EPS × payout) / P = DPS / P`。B（24~36 个月慢熊，跌幅 R 的 3.0~3.5 倍）/ C（24 个月通缩式阴跌，跌幅 R 的 0.8~1.2 倍）下，**分子与分母反向运动**：

| 力量 | 方向 | 在 B / C 的相对强度 |
| :--- | :--- | :--- |
| 价格 P 缓慢下行（分母效应） | 抬升 dy | B 强、C 弱但持续 |
| 盈利 EPS 下移（分子效应） | 压低 DPS → 压低 dy | **B/C 均强**：需求走弱、通缩下名义营收承压；000922 权重集中于银行/煤炭/交运，行业侧 §2.2 判定其对「通缩式阴跌」中高~高敏感【事实·中】 |
| 派息率 payout 变化 | 不定 | 「保卫名义 DPS」→ payout 被动抬升；「随盈利削减」→ payout 持平。属管理层决策，**不可从价格序列推断** |
| 分红决策滞后 | 平滑、滞后 | 年报(3-4月)→股东大会(4-5月)→实施公告→除权除息(5-7月)，【事实·核对，§5.2】，滞后约 2~4 季度 |

**净效应不确定、且强路径依赖**【判断·中】：
- 若 P 跌得比 DPS 快 → dy 上升（分母主导，类似 A 但更缓）；
- 若 DPS 削减快于 P → dy 下降（分子主导）；
- 二者谁快取决于**未被观测的盈利与派息决策**，不能由「设定相关性与目标累计跌幅」的 Cholesky 合成序列（Phase 2 §六构造约定 2）推出来。

**因此**：把真实历史插值股息率（一段「已实现」的分子分母联动结果）套到 B/C 构造路径上，等于**假设构造情景下的盈利/派息/价格联动恰好复刻某段真实历史**——这在情景构造下没有依据，且会把历史里「一次性相对重估」「TTM 口径切换」等噪声一并带入（§1.9 给出实证）。**这是比 A 路径更隐蔽的不自洽**：A 至少方向可判（分母主导），B/C 连方向都不可判。

### 1.4 机制问题 ③（补充）：除息季节性与 `/252` 均匀摊的错配

【事实·核对·中 / 不进引擎】联网核对（Wind 经媒体转引，检索 2026-11-07）：**中证红利成份股 78% 的除权除息事件集中在每年 5~7 月**，6 月为峰值（平均 37 只成份股实施分红）、7 月次之（35.6 只）；2016-07~2026-07 共 121 个自然月中，**6 月价格指数（000922）平均 −2.52%、全收益指数（H00922）平均 −1.08%，分红贡献 +1.44%**（来源：腾讯新闻 2026-07-24 引 Wind；A 股整体 2026-06 以除权除息日为基准已实施及将实施 2025 年度分红 >1700 家、累计派现 5690 亿元，来源：中国证券报/中国经济网 2026-06-28~29 引 Wind）。

【推断·中】引擎 `divCash = .../252` 把年度分红**均匀摊到每个交易日**。这与事实错配有两层后果：
1. **净值路径形态失真**：真实 6 月「价格指数因除息被动回落、同时收到一笔集中股息」，引擎却把这笔股息平摊全年，导致 6 月净值被相对低估、其余月份被相对高估。对「账户回撤首次达 R」的**触发日判定**尤其敏感——回撤是路径量，路径形状改变可能改变触发日（Phase 2 §5.4 已证触发日对所有口径假设高度敏感）。
2. **与第 5 条的 20 日锁定窗口直接相关**：若锁定+复核窗口覆盖 5~7 月，实际股息现金流缺口会**显著高于均匀摊估算**；若落在 1~3 月（如 Phase 2 的关键触发日 **2016-01-28**，20 日末 2016-03-03，§5.4），缺口**近似为零**（§2.4 展开）。因此「股息不计入」在特定窗口是**局部成立的近似**，而非纯假设——这是 §1.8 判断的关键。

### 1.5 机制问题 ④（补充）：合成序列与「真实历史隐含 DPS」的隐蔽混拼

【判断·中】Phase 2 §六构造约定 2 要求「合成序列必须单独存放并标注『人工构造、非历史事实』，**严禁与真实价格序列混拼命名**」。但股息率插值序列 `dyHS/dyHL` 的**分子本身是从真实历史价格与真实分红实现中隐含出来的**（`dy = DPS/P`，P 为历史价格）。把它接到合成价格路径上，本质上是一次**未标注的口径混拼**：分母换成了合成价格、分子仍携带真实历史信息。建议在 Phase 5 的合成路径产出物中，把「股息率输入」也一并标注为「**由真实历史观测外推、非该合成情景的内生量**」，否则违反 §三单一数据源声明的精神。

### 1.7 对 Phase 5 净效应检验的**方向性影响**（不给具体绩效数字）

【推断·中】按 P1 修正后，方向在 A 与 B/C 之间**不一致**，这本身必须分路径报告、不得平均：

| 压力路径 | 现有口径 (a) 相对修正口径 (b/c) 的偏差方向 | 对 R 余量 / 触发判定的方向 | 对「减半条款净效应」判定的方向 |
| :--- | :--- | :--- | :--- |
| **A 急跌** | 现有口径随市值缩水而**低估**下跌途中 carry → 回撤被高估 | 修正后余量**略增**、触发**更不易** | 条款触发机会变少 → 减半的边际作用**更弱**（但为二阶小量，不改变符号判断） |
| **B 慢熊** | 若采用 P3 的 DPS 逐年削减，carry 随时间递减，低于「固定 DPS」口径 | 修正后（含削减）余量**略减**、触发**略更易** | 与 A **方向相反** |
| **C 通缩阴跌** | 名义 DPS 黏性可能更强（不愿削减名义分红），但盈利下移方向相反，净效应最不确定 | **不可预判**，须由敏感性网格给出 | 应作为「口径不确定」项单列，不给单一符号 |

**三条限定**【判断·高】：
1. 股息 carry 相对账户总量是**二阶小量**：按本地 34 点日频均值，权益端加权股息率 `dy_port = 0.75×2.3091% + 0.25×4.0358% ≈ 2.74%`，乘以 40% 权益敞口 ≈ 账户层 1.1%/年量级，且减半后同比例缩水。故**修正股息建模不可能翻转「边界敏感」这一裁定**，只会在薄余量（主口径 R=20% 余量 0.309pp，【事实·中】Phase 2 §4.2）附近移动小数位。
2. 正因其量级小、而余量又薄，**它恰恰是「边界敏感、非结构性免疫」的又一个独立来源**：任何口径微调都能把 0.309pp 推过零。Phase 5 应把它列入口径敏感性网格，**但不得据此对第 5 条存废下结论**。
3. 减半后 `vD/vH` 减半 → `divCash` 在现有引擎里**自动减半**，这一点是**自洽**的（份额减半 ⇒ 应得股息总额减半，符合 §1.1 恒等式）；恢复买回后份额与 carry 同步恢复。故 **Phase 5 状态机无需为「减半」单独改 divCash 逻辑**，只需在 P1 修正下保证 `u` 随 `eqTarget` 正确缩放。

### 1.8 特别回应：「股息不计入」是合理压力口径，还是口径错误？

> 背景【事实·中，Phase 2 §4.4】：`股息 计入 → 不计入` 是**唯一**使 R=20% 从「不触发（余量 +0.309pp）」变为「触发 1 次（余量 −0.082pp，2016-01-28）」的**单项**口径变化之一（另两项为「现金 −1pp」「全期 1.3% 前瞻」）。主理人据此指出「本轮第 5 条检验结果对股息现金流建模方式高度敏感」。

**我的判断【判断·高】：作为主口径 / 基准口径，它是口径错误；作为敏感性网格里的下界压力口径，应当保留，但必须重命名并限定用途。**

**（1）为什么是口径错误（若当基准）**【推断·高】：本轮价格序列是**价格指数、不含股息**（Phase 2 §2.2【事实·高】）。若同时把股息收益整体置零，等于**双重遗漏权益总回报**——净值路径只剩价格涨跌，系统性低估权益长期收益，与「用价格指数 + 单独建模股息」的设计前提直接冲突。v1.5 主口径明确「股息计入」（`bt_final.js:39,54`），行业侧 §3.4 的「不含股息」是自己声明的**简化近似口径**、且已注明「与 19.69% 不可直接比较」（Phase 1 行业侧 §0 第 4 条、【事实·中】）。把它升格为基准，会**制造**而非**揭示**触发。

**（2）为什么仍应保留在敏感性网格**（三条独立理由）：
- **① 它是 carry 归零的下界压力测试**【判断·中】：股息建模本身是多层近似（半年度 34 点线性插值 → 日频、TTM 股息率作未来一年收益代理、均匀摊 252 日、非真实除息现金流，Phase 2 §2.2 / §九第 3 项）。「carry 全部落空」恰好给出「这套近似完全失效」的保守边界。Phase 2 §4.6 已明确：口径敏感性网格是**诊断工具**、说明「按构造不触发」这一断言的脆弱性，**不是策略表现**。
- **② 在关键触发窗口它局部近似成立，并非纯假设**【推断·中】：Phase 2 定位的最大回撤日 / 触发日 **2016-01-28（idx 1474）**，20 日锁定末 2016-03-03（§5.4）；A 股年度分红除权除息集中在 **5~7 月**（78%，【事实·核对·中】§1.4），1~3 月为**实施空窗期**。因此在该具体窗口，「锁定/复核期间股息现金流 ≈ 0」是**有节奏依据的局部近似**。→ **建议把它重新诠释为「触发窗口内股息 carry 缺口」的局部压力口径**，而非「全期股息收益归零」。
- **③ 它检验的是「边界敏感」而非「条款有效性」**【判断·高】：Phase 2 §4.6 裁定「边界敏感、非结构性免疫」的证据之一正是它。保留它 = 保留对薄余量的诊断能力；删除它 = 掩盖一个已被量化的口径脆弱点。

**（3）处置建议**【判断·高】：
- **重命名**：网格维度由「股息 计入 / 不计入」改为「**① 股息 carry 计入（主口径）｜ ② 股息 carry 归零（下界压力口径）｜ ③ 季节性 DPS 路径（第三口径，P7/P9）**」；
- **限定用途**：② **不作 V0 对照基线、不进状态机绩效比较、不用于条款存废裁决、不写入任何触发条件**；只出现在「口径敏感性网格」与「数据局限披露」两处；
- **显式标注**：② 与「价格指数不含股息」叠加会双重遗漏权益回报，**仅作敏感性下界**；
- **建议新增第三口径**：按 §1.4 的除息季节性（5~7 月集中）构造 DPS 现金流路径，使「全计入 / 全不计入」两个极端之间有可解释的中间态。但**该口径所需逐日除息日历当前「数据待更新」**（Phase 2 §九第 3 项），**严禁用外部核对数据混拼补齐**；若 Phase 5 无法在统一基线下构造，则明确写「第三口径数据不足、本轮未检验」，不得估算。

### 2.1 政策基线（已核实，标注来源与日期）

**A 股直接持股 · 股息红利差别化个人所得税**【事实·核对·中，政策原文】：
- **《关于上市公司股息红利差别化个人所得税政策有关问题的通知》财税〔2015〕101号**，财政部 / 国家税务总局 / 证监会 2015-09-07 发布，**自 2015-09-08 起施行**（来源：国家税务总局官网 `chinatax.gov.cn`，检索 2026-11-07）。
- 持股 **>1 年**：股息红利所得**暂免征收**个人所得税（税负 0）；**1 个月以上至 1 年（含）**：暂减按 50% 计入应纳税所得额、统一 20% 税率 → **实际 10%**；**1 个月以内（含）**：全额计入 → **实际 20%**。证监会深圳局投教案例明示「持股 1 个月至 1 年税负 10%、1 个月以内 20%、超过 1 年 0」（来源：`csrc.gov.cn/shenzhen`，检索 2026-11-07）。
- **关键清算机制（主理人转交未含、本轮补出）**：「上市公司派发股息红利时，对个人持股 1 年以内（含 1 年）的，**上市公司暂不扣缴**个人所得税；**待个人转让股票时**，证券登记结算公司根据其持股期限计算应纳税额，由证券公司等股份托管机构**从个人资金账户中扣收**」。中登公司于卖出股票下一交易日开市前将应扣缴数据发送证券公司，代扣期限 31 个工作日（来源：财税〔2015〕101号 第二条；证监会深圳局投教案例，检索 2026-11-07）。
- **历史档位**：财税〔2012〕85号 自 **2013-01-01** 起，持股 >1 年「暂减按 25% 计入」（实际 5%），2015-09-08 后改为免征（来源：经济日报 / 上海市税务局，检索 2026-11-07）。**2010-2012 年段适用档位本轮未逐条核对，标注「数据待更新」**。

**基金实现下的税务**【事实·核对·中】：
- **《关于开放式证券投资基金有关税收问题的通知》财税〔2002〕128号**（2002-08-22，国家税务总局官网）：「对基金取得的股票的股息、红利收入…由上市公司…**在向基金支付上述收入时代扣代缴 20% 的个人所得税**；**对投资者（包括个人和机构投资者）从基金分配中取得的收入，暂不征收个人所得税和企业所得税**」；「对个人投资者申购和赎回基金单位取得的差价收入…暂不征收个人所得税」。财税字〔1998〕55号 另明确「基金向个人投资者分配股息、红利、利息时，不再代扣代缴个人所得税」。

- 这**正是 v1.5 §5.1「股息税不重复计入（ETF/场外指数基金层面已扣）」的政策依据**【事实·中，`投资策略规划_v1.5.md` line 60、line 235】。

> **一处口径局限（研究注释，不改变任何回测数字）**【判断·中】：v1.5 的「10% 保守值」是**跨 2010-2026 全期统一比例**（`bt_final.js:188,195,227`），而期间至少经历 **2013-01-01、2015-09-08 两次税制档位变更**；且它是 `tax = divCash × divTax` 的**固定比例税**（`bt_final.js:55`），**不含持股期限、不含卖出清算、不含先进先出批次**。故该保守值**无法刻画减半→买回造成的路径依赖税负**，只能作为静态上界参照。

| **真实执行摩擦（须披露）** | **场外指数基金申赎确认与到账延迟**：赎回款到账前既不享权益、也未必立即计现金利息 → 现金收益在途缺口；**ETF 折溢价、买卖价差、流动性冲击** v1.5 §5.3 已明确未计 | 【事实·中】v1.5 line 235；Phase 2 §九第 1 项；行业侧 §3.2【判断·中】。此属 etf-analyst 职责，本成员不越权定量 |

> **小结**【判断·高】：**在主实现（ETF / 场外指数基金）下，第 5 条的减半与恢复动作对分红资格、除息日、持有期限与投资者层面股息税基本无实质影响**；真正需要在执行层披露的是**申赎/到账延迟导致的现金收益在途缺口**与**恢复时点不确定导致的股息 carry 缺口**（§2.4）。

### 2.3 ② 直接持股实现下，持有期限被重置的影响

【判断·中】直接持股**不是本方案主实现**（v1.5 主口径按 ETF/场外基金），以下仅为**保守值口径下的补充披露**，且 `final_audit_data.json → costs` 的 10%/20% 是**全期统一比例税的静态对照**，不是路径依赖模拟：

1. **减半卖出当日即触发补税清算**【判断·中】：依财税〔2015〕101号 第二条，派息时暂不扣缴，**转让股票时**按该批股份持股期限清算补扣。故「卖出总资产 20%」会立即对**已被卖出那部分股份此前已取得的股息**做一次税务清算。
   - 触发时点通常在账户回撤达 R 之后；本方案为 40% 静态敞口的长期配置，被卖出批次大概率已持有较久（>1 年 → 免税），故**该次清算补税多为 0 或 10%**【推断·低，无持仓台账实测，数据待更新】。
2. **买回后新份额的持股期限从 0 重启**【判断·中】：新买入份额若在 ≤1 个月内收到股息 → 按 20%；1 个月~1 年 → 10%；>1 年才回到免税。**恢复买回若发生在 5~7 月除息高峰前不久，新份额最短持有期会放大税负**（§1.4 季节性）。
3. **量级判断（静态对照，非绩效）**【事实·中 + 推断·中】：`final_audit_data.json → costs` 显示「全期统一 10% 股息税」年化 3.665%（较基线 −0.12pp）、「20%」年化 3.548%（−0.23pp），**两档之差约 0.117pp/年**（70/30 审计口径、全期统一比例、无成本/T+0）。这是**「若全期按 20% 计」的上界静态对照**，**不是**「减半买回导致局部重置」的实测值；后者需要持仓批次台账，当前**数据待更新**。
4. **建模缺口**【判断·中】：`bt_final.js:55` 的 `tax = divCash × divTax` 是**固定比例、无期限、无卖出清算**，因此 **v1.5 的 10% 保守值在结构上无法表达「减半→买回」造成的期限重置**。若 Phase 5 需要在直接持股实现下评估该动作，**必须新增批次/持有期状态变量**（超出本轮数据基线，且属 Phase 4/5 职责，本成员不越权实现）。

> **纪律限定**【判断·高】：上述影响量级小、且直接持股非主实现，**不得**被用作支持或反对第 5 条存废的理由；仅作为 v1.6 执行层「实现方式差异」的脚注。

### 2.4 ③ 恢复时点不确定（`reviewLagDays ∈ {20, 40, 60, ∞}`）造成的股息现金流缺口：公式与量级判断

> 参数来源【事实·中】：Phase 2 §7.4 `lockDays=20`、`reviewLagDays ∈ {20,40,60,Infinity}`、`cutRatio=0.5`、`eqBase=0.40`；§7.1 明确 `Infinity` 等价于 `recoverMode='none'`。

**解析公式**【推断·中】（**账户层、占 nav 的百分比；非绩效、非回测输出**）：

设 `ΔE = E·(1 − cutRatio) = 0.40 × 0.5 = 0.20` 为减半后减少的权益市值占比；`dy_port(t) = 0.75·dyHS(t) + 0.25·dyHL(t)` 为权益内按 75/25 的加权股息率；`L` 为「锁定 + 书面复核延迟」的交易日数；`cashRate` 为现金到账利率。

```
毛缺口(账户层)   G(L) = ΔE · dy_port · L / 252
净缺口(扣替代现金利息) N(L) = ΔE · (dy_port − cashRate) · L / 252
L = ∞ 时：        G = ΔE · dy_port /年 ； N = ΔE · (dy_port − cashRate) /年
完整形式：        G = Σ_{t=trigger}^{recover} [ E·(1−cutRatio)·nav_t · dy_port(t) ] / 252 / nav_0
```

**`dy_port` 两个口径**（均来自本地 34 点，【事实·高】）：全期观测点均值口径 `0.75×2.3286% + 0.25×4.0588% = 2.7611%`；2026-11-06 时点口径 `0.75×2.8206% + 0.25×4.1039% = 3.1414%`。`cashRate` 取基准 1.3%（v1.5 §2.3 分段假设 2022-2026 段，【事实·中】）。本地 `node -e` 重算（2026-11-07）：

| L（交易日） | 毛缺口 G（账户层 pp） | 净缺口 N（扣 1.3% 现金利息，pp） |
| :--- | :--- | :--- |
| 20（基准，最有利于条款的乐观下界） | **0.0438 ~ 0.0499** | **0.0232 ~ 0.0292** |
| 40 | 0.0877 ~ 0.0997 | 0.0464 ~ 0.0585 |
| 60 | 0.1315 ~ 0.1496 | 0.0696 ~ 0.0877 |
| ∞（永不恢复） | **0.5522 ~ 0.6283 / 年** | **0.2922 ~ 0.3683 / 年** |

**四条必须随公式一起声明的限定**【判断·高】：

1. **这是解析近似，不是绩效、不是回测结果**：假设 ΔE 与 dy_port 在窗口内恒定、nav 近似不变、无交易成本；**不进 Phase 5 绩效表**，仅用于量级判断。Phase 5 应以状态机 `counters.cutCount/recoverCount` 与逐日 `nav` 实测核对符号与量级（见 §6 命题 D3）。
2. **与价格侧机会成本不同口径、不可相加替代**：行业侧 §3.3 的 20 日机会成本上界 **1.19~1.54pp**【事实·中】是**价格反弹侧**账户层机会成本；本表是**股息 carry 侧**现金流缺口，量级小约**一个数量级**。二者可并列披露，**不得相加、不得互相抵扣、不得用一个否定另一个**。
3. **季节性会破坏均匀摊估算**【推断·中 + 事实·核对】：78% 除权除息集中在 5~7 月（§1.4）。若 L 窗口覆盖该区间，真实缺口会**高于**上表；若落在 1~3 月（如 2016-01-28→2016-03-03），则**近似为 0**。**上表是均匀摊口径，不能当成任一具体触发时点的实测值**。要按除息日历加权需**逐日除息序列**，当前 **Phase 2 §九第 3 项「数据待更新」**，**严禁**用 §5.2 的外部核对数据混拼补齐。
4. **减半后 `ΔE` 部分的资金转为现金并按 `cashRate` 计息**（`bt_final.js:57`），故**净缺口 N 才是经济意义上的缺口**；上表已给出两者。L=∞ 时净缺口约 0.29~0.37pp/年是**长期年化量级**，不是一次性损失。

> **给主理人的一句话**【判断·中】：恢复时点不确定带来的**股息 carry 缺口是可估算的、方向确定的、但量级很小（L=20~60 时账户层 0.02~0.15pp）**；它**不足以**成为第 5 条存废或 `reviewLagDays` 取值的裁决依据。真正的执行层摩擦在价格侧机会成本与申赎到账延迟，不在股息税或股息 carry。

### 3.2 明确论证：为什么它们**只能**支撑 25% 静态参数

【判断·高】四条独立理由：

1. **性质错配：慢变量 / 水平量 ≠ 二元事件量**【推断·高】。ROE 从 10.48%→8.70%、收入连续三年负、派息率比值 1.27→0.975、PE 比 0.4116→0.6698，都是**跨年度、连续、需专业解读的状态变量**；第 5 条的触发结构是「`dd ≥ R` 的二元事件，当日收盘即可机械判定、T+1 成交」。把连续慢变量塞进二元事件，要么必须人为设阈值（把连续量离散化 → 直接违反铁律），要么**无法判定触发日**，条款在回测中不可实现。
2. **观测频率与可得性不匹配**【推断·高】。ROE/收入/派息率是季报/年报口径，有 1~4 个月滞后且需财报汇总；PE 比、息差、股息率差是估值信号；基金净流出是资金流信号。第 5 条要求「当日收盘判定、次日成交」，这些信号**在触发日不可得、不可逐日复现、且多口径并存**（如 PE 9.06/70.1% 分位 vs 12.49/99.6% 分位，【事实·中】）。Phase 2 §三已明确「宏观读数与联网行业权重**不进回测引擎**」，把这些信号接进状态机就是**混拼**。
3. **作用维度错配：权益内相对权重 ≠ 总敞口 E 的时机**【判断·高】。ROE 下行、派息率恶化、折价收敛，影响的是「**红利相对沪深300 的长期性价比与 carry 可持续性**」→ 对应第 2 条权益内 75/25 的**静态取值**（上一轮据此 30%→25%），或对应长期预期收益假设。而第 5 条作用的是「账户回撤达 R 时把**总敞口 E 减半一次**」的**时机与幅度**。「红利性价比下降」在逻辑上**不蕴含**「回撤达 20% 那一刻应该减仓」——把水平信号错配成择时信号，是范畴错误。
4. **已有制度出口，无需进规则**【事实·中】。v1.5 第八章季度复核已包含「复核标的费率、流动性、**分红可持续性**；记录两指数实测股息率（**仅留档，不触发动作**）」（line 259）；第八章护栏 ② 已含「现金到账利率连续两季 <1.0% → 按实际利率重算 R 余量并**书面确认**」（重算 ≠ 减仓）。**分红可持续性已有静态审阅与书面复核的既有通道**，把它写进第 5 条既不必要、又破坏一致性。

### 3.3 若写进第 5 条触发条件：违反什么原则、产生什么后果

**违反的五条原则**【判断·高】：
| # | 原则 | 具体违反 |
| :-- | :--- | :--- |
| 1 | 第 4 条「不做择时」 | 以基本面/估值/资金流信号驱动敞口变更 = 隐性择时（v1.5 §3.3 已认定第 5 条本身是唯一残留隐性择时，再加信号只会加重） |
| 2 | Phase 0 铁律「风险信号 ≠ 规则输入」 | 直接把被明令「仅作研究信号」的量写成规则输入 |
| 3 | 第 2 条 75/25 不设触发式调整 | 一旦允许基本面信号驱动动作，就打开了「按信号调权益内权重」的口子，与 25% 单点硬上限冲突 |
| 4 | Phase 2 §三单一数据源 | 这些信号来自 NeoData / 外部网站、快照日不一、不进引擎；混入即制造无法追溯的数值 |
| 5 | 可复现性与前视偏差纪律 | Phase 2 §7.3 前视偏差检查清单要求「触发判定只用当日收盘后可知的 nav」 |

**产生的五类后果**【推断·中】：
1. **前视偏差**：用当期财报值判定历史触发日，而财报在回撤日尚未公布 → 用未来数据判定过去动作，回测结论作废。
2. **自由参数膨胀 / 过拟合**：为 5~6 个信号各设阈值、滞后阶数、连续确认期数，样本内可把触发调到「恰好想要」的位置；v1.5 §4.4 已驳回「用一次性归因推翻全部稳健性检验是另一种过拟合」，此处同理。
3. **信号与 R 语义冲突**：出现「基本面恶化但未达 R」或「达 R 但基本面未恶化」时，条款该不该触发无定义；且 v1.5 line 193 已证「同一输入在不同分位口径下动作相反」。
4. **循环论证叠加**：与 v1.5 §3.3 承认的「R→E 表由历史 MDD 略小于 R 反推」同构，再叠一层用历史信号拟合触发。
5. **尾部保护反而恶化（最实质）**：基本面信号在急性崩盘中是**滞后或同向**的——盈利下修在危机后 1~2 个季度才公布，资金流在恐慌中最差。它们不会在崩盘当下预警，反而**在底部发出减仓信号**，把减半坐实为 v1.5 §3.3 已记录的「暴跌后追跌减仓」。行业侧 §1.4 亦证急性段两指数同跌 97.5~98.8%、缓冲最薄。

### 3.4 反证的诚实呈现（唯一成立的落点）

【判断·中】是否存在「这些信号应当影响第 5 条」的合理情形？**有，但只能落在静态层与情景参数层，不能落在触发层**：

- **落点 A（静态参数）**：红利 carry 可持续性下降 ⇒ 长期预期股息收益下修 ⇒ 应在**定期审阅**中作为静态 E / R 设定的输入。这与宏观侧「R 的设定应覆盖慢熊而非仅快跌」、行业侧「一次性相对重估不可外推为稳定尾部保护」完全同构，且仍在 v1.5 第 1 条 R→E 查表机制内。
- **落点 B（压力路径构造参数）**：正是本报告 §1.6 的 **P3（B/C 路径 DPS 年度削减率 κ）与 P6（派息率约束）**——把「收入三年负 / ROE 下行」翻译成**情景假设里的 DPS 路径**，用于压力测试，**而不是**翻译成触发条件。这两者都是「事前静态参数 / 主观情景参数」，不违反第 4 条。

> **故反证不成立为「写进第 5 条触发条件」，只成立为「写进静态审阅输入与压力路径参数」。**【判断·高】

### 3.5 对 25% 取值的独立复核意见（不越权，仅研究注释）

【判断·中】从分红 carry 与基本面角度：
- 这些信号**支撑 25% 的方向**（相对 30% 下调、取授权区间下沿），与 v1.5 §4.5「为何是 25% 而非 20%」的裁决一致；
- 但**隐含派息率比值 1.27→0.975 尤其值得注意**：它意味着红利相对沪深300 的**股息优势已基本消失**（比值趋近 1），这**削弱了「用倾斜换 carry」的原始理由**；叠加 `final_team_notes.json` 个股研究员「红利高息来自低估值而非更高分红率（支付率 35.9% < 沪深300 37.1%）」【事实·中】，说明红利的高股息率更多是**估值折价（分母）**而非**分红能力（分子）**——与 §1.9 的实证一致。
- 同时它们**不支撑把 25% 进一步下调到 0**，更不支撑「因基本面恶化而在尾部减仓」：账户层穿透后红利仅占总资产 10%（40%×25%），且第 2 条为不可动摇边界。
- **「2026Q3 净流出 4.8%」是典型顺周期资金流噪声**，与分红现金流可持续性无直接因果关系；把它写进规则尤其危险——会在赎回压力最大时叠加减仓，形成反身性放大【判断·中】。

**结论**【判断·高】：这些信号**足以支撑「25% 已是授权区间下沿、不再上调」，但不足以、也不应该驱动任何触发式动作**；与行业侧「25% 不承担尾部保护职能」一致（§4）。

## 四、【任务 4】对行业侧保留意见①「25% 不承担尾部保护职能」的独立判断

### 4.1 必须先澄清的一处量纲问题（否则下游必错）

【事实·高 + 事实·中】主理人给出「+0.48pp 增益中价格差 0.27pp / 股息率差 0.21pp；纯 carry 反事实 +0.21pp；急性段缓冲 0.01~0.49pp」。本地核对：

- `final_audit_data.json → attribution`：`single 3.297 / priceOnly 3.567 / full 3.781 / totalGain 0.48 / priceGain 0.27 / divGain 0.21 / divShare 44.21`——**单位是 CAGR 年化收益百分点（pp/年）**，由 `bt_final.js:113-120` 的 `mix().m.cagr` 相减得到；「纯 carry 反事实」= `mix({w:0.30, dyD: V.dyHS})`（把红利股息率替换成沪深300 股息率）与 `mix({w:0.30})` 的 CAGR 差。
- 行业侧「急性段账户层缓冲 0.01~0.49pp」是**峰谷回撤幅度口径**（`账户回撤 ≈ E × 权益组合跌幅` 一阶近似，Phase 1 行业侧 §0 第 4 条）。

> **⚠️【判断·高】两者量纲不同、数值接近纯属巧合，绝不可相减、互证或并列成「增益 ≈ 缓冲」。** 若下游把「carry 增益 0.21pp/年」与「急性段缓冲 0.49pp」直接比较，会得出「分红 carry 覆盖了尾部缓冲」的**错误结论**——前者是全期年化收益、后者是单段回撤幅度，且时间尺度相差一个数量级。建议 v1.6 在这两个数字首次出现处各加单位后缀。

**另需注意两套归因口径并存**【事实·中】：v1.5 §4.4 / 估值定价师对同一 0.48pp 给出「约 **67%** 来自一次性相对重估、纯 carry **0.154pp/年**」；`bt_final.js` 机械分解给出「价格 **0.27** / 股息 **0.21**（44.21%）」。二者**方法不同**（前者按 PE/PB 比变化归因，后者按「股息率差反事实」分解），数值不同但**定性同向**（价格贡献 > carry 贡献，且价格贡献主要来自一次性、已兑现的重估）。**并列呈现、逐项标源、不混拼、不换算**（沿用团队一贯纪律）。

### 4.2 分红 carry 维度判断

【判断·高】**支持**「25% 不承担尾部保护职能」，理由：

1. **carry 是「缓释」不是「保护」**【推断·高】：纯 carry 增益 0.21pp/年（或估值定价师口径 0.154pp/年）是**缓慢、均匀、近似恒定、恒为正**的小额现金流，**不随回撤加深而增大**。尾部保护要求的是「在极端下跌时提供非线性的、与跌幅正相关的缓冲」（凸性）。A 路径跌 40~50% 时，carry 仍是那 0.2pp/年量级，仅占跌幅的约 0.5%——**量级与性质都不成立**。
2. **carry 在尾部甚至可能缩水，是顺周期弱项**【推断·中】：§1.2 证现有引擎在急跌中让 carry 随市值缩水；§1.3 证 B/C 情景 DPS 可能削减；§2.4 证减半后 carry 按份额同比例减半。三者都指向「越需要保护时 carry 越薄」，与行业侧「越需要保护时缓冲越薄（最差 5% 日 +0.328pp、≤−3% 日收窄到 +0.225pp）」**同构**。
3. **carry 的来源本身在退化**【事实·中】：隐含派息率比值 1.27→0.975、支付率 35.9% < 37.1%（§3.5），说明红利高息主要来自**估值折价（分母）**而非分红能力（分子）；而折价已收敛（PE 比 0.4116→0.6698、息差 369.7→128.3bp）。**carry 优势的历史来源正在消失**，更谈不上承担尾部职能。

### 4.3 价格行为维度判断

【判断·高】**支持**，理由：

1. **急性段缓冲实质为零**【事实·中】：2015 股灾 1.0 / 2016 熔断 2.0 账户层缓冲仅 **0.01~0.04pp**，2018 全年 0.49pp、2020-03 0.27pp；相对 40%+ 的跌幅，占比 <1.3%。且两指数急性段相关 0.9637~0.9851、同跌 97.5~98.8%（Phase 1 行业侧 §1.1/§1.2）。
2. **唯一显著缓冲来自不可重复的一次性重估**【事实·中 + 判断·中】：2022 段缓冲 1.46~1.75pp、2021-2024 长慢熊 3.91pp，但行业侧 §1.4 明确「该分化与『一次性相对重估』期重合，**不可外推为稳定尾部保护**」；估值定价师「67% 增益已兑现」、v1.5 §4.4「相对折价已从极端回到历史中枢附近（PE 比 +62.7%）」指向同一段。**把一次性、慢熊期的相对重估当作急性尾部保护，是样本外误用。**
3. **尾部相关性趋同**【事实·中】：Phase 2 §5.1 峰谷段相关 0.9694~0.9949；急性段「越极端、红利相对优势越小、同跌比例越高」。价格行为上 25% 在需要保护时不提供分散化。

### 4.4 独立结论与措辞补强

> **【判断·高】行业侧保留意见①表述准确，建议采纳。** 从分红 carry 与价格行为两个维度，25% 提供的是**水平收益垫**（恒定、小额、与尾部无关）与**一次性相对重估收益**（不可重复、发生在慢熊期），**均不构成尾部保护职能**。

**两点措辞补强建议（不推翻原意）**【判断·中】：
1. 建议写为：「**75/25 与第 5 条相互独立；25% 不承担尾部保护职能。其账户层增益主要来自一次性相对重估与恒定股息 carry，二者在急性回撤中均不提供有效缓冲（0.01~0.49pp）**」——补上机制归因，避免下游把「不承担」误读为「完全无增益」（+0.48pp/年的增益真实存在，只是性质不是保护）。
2. 补一句边界：「**第 5 条是对总敞口 E 的同比例缩放，减半后权益内仍按 75/25 reset 重置、不引入结构畸变**（Phase 2 §7.5、行业侧 §3.1）；故第 5 条的存废/触发既不改变 25% 的相对权重，也不改变其 carry 与价格贡献的性质。」——把「相互独立」落到可执行层。

**一条反向约束（提请 Phase 4 注意，不越权裁决）**【判断·中】：若 v1.6 因删除/替换第 5 条而新增**「以红利为载体的尾部保护」**（例如「达 R 时只减沪深300、保留或增持红利」），那就在事实上把 25% 赋予了尾部职能——这既与保留意见①冲突，也违反第 2 条「不设触发式调整」。本报告**明确反对**该设计方向（与行业侧备选 C 一致），但**最终裁决归 Phase 4/6**。

## 六、【任务 6】交回 Phase 4 策略卡 / Phase 5 回测的可检验命题与建模约束

> 三条均写成「什么算成立 / 什么算失效 / 什么算数据不足」，**不含结论性断言、不含绩效数字**，全部在 Phase 2 统一基线下检验。

### 命题 D1｜压力路径的股息建模必须「DPS 与价格分离」（建模约束）

- **约束内容**：Phase 5 在 A/B/C 合成路径上不得沿用 `v^synth · dy^hist`；须按 §1.6 P1 令 `divCash = u · DPS(t)`（或 `dy(t)=DPS(t)/P(t)` 动态重算），并固定 P5 诊断带、P2/P3 的 `κ` 网格、P4 滞后阶数。V0 对照基线必须与 `mix(B.P_MAIN_OPT, {eq})` **逐位对齐**（Phase 2 §七）。
- **成立判据**：在 A 路径（跌幅 40~50%）下，「份额×DPS 固定」口径与「市值×历史插值 dy」口径的累计 divCash 出现**方向稳定且可复现的分离**（前者不随价格缩水、后者随市值缩水），且分离幅度与价格跌幅单调相关；B/C 路径下 `κ` 网格给出**单调、方向可解释**（B 与 A 方向相反须单独报告）的余量变化；V0 对齐校验通过。
- **失效判据**：两种口径在 A 路径下累计 divCash 差异 <10% 或方向不稳定 → 说明该建模选择对结果不敏感，可从敏感性网格降级为脚注；或 V0 未逐位对齐 → 整轮结果不可用。
- **数据不足判据**：无 DPS 绝对额序列、无逐日除息日历（§5.3 第 1/2 项）→ 不得把 `κ`、`payout`、季节性权重标定为「事实」；须在报告中逐项标注「主观情景参数」，且**不得**用 §5.2 外部核对数据混拼补齐。

### 命题 D2｜「股息不计入」的口径定性与第三口径可归因性

- **约束内容**：敏感性网格的股息维度按 §1.8 重命名为「① carry 计入（主口径）｜② carry 归零（下界压力口径）｜③ 季节性 DPS（第三口径）」；② **不作 V0 对照、不进状态机绩效比较、不用于条款存废裁决、不写成触发条件**。
- **成立判据**：② 对 R 余量的影响被限定在「口径敏感性网格」与「数据局限披露」两处；R=20% 在 ①/② 之间的触发差异（Phase 2 §4.4：+0.309pp → −0.082pp、2016-01-28 触发 1 次）**被明确归因于「股息建模敏感性」，而非「条款结构性会触发/不会触发」**；且 ③ 若在统一基线下可构造，能给出介于 ①② 之间、方向可解释的结果。
- **失效判据**：下游把 ② 当作基准口径、或据 ② 直接推断「第 5 条按构造会触发 / 结构性失效」、或把 ② 写进策略卡正文作为规则输入 → 口径被误用，须回退。
- **数据不足判据**：无逐日除息日历 → 无法判定具体触发窗口（如 2016-01-28→2016-03-03）的真实除息事件数，故「该窗口 carry≈0」只能保持【推断·中】，**不得升级为事实**；③ 若无法在统一基线下构造，须明确写「第三口径数据不足、本轮未检验」，不得估算。

### 命题 D3｜减半 / 恢复的股息 carry 缺口量级与税务执行披露

- **约束内容**：Phase 5 状态机须能输出 `counters.cutCount / recoverCount` 与逐次触发的 `L = lockDays + reviewLagDays`（Phase 2 §7.8），并按 §2.4 解析公式给出「账户层、占 nav、非绩效」的 carry 缺口估算；v1.6 执行层按 §2.5 三级披露。
- **成立判据**：状态机实测缺口与解析公式在**符号一致、量级同一数量级**（L=20~60 时账户层 0.02~0.15pp 净缺口 / 0.04~0.15pp 毛缺口；L=∞ 时 0.29~0.37pp/年 净 / 0.55~0.63pp/年 毛）；且该量级**始终小于**行业侧价格侧机会成本上界 1.19~1.54pp【事实·中】约一个数量级；减半后 `divCash` 随 `u`（份额）同比例缩水、恢复后同步恢复（§1.7 第 3 条自洽性）。
- **失效判据**：实测缺口超出解析量级一个数量级以上，或符号相反 → 说明状态机的 `u / eqTarget / divCash` 缩放不自洽，须回查 §1.1 恒等式；或 `L=∞` 路径下 carry 未随份额永久减半 → 状态变量有误。
- **数据不足判据**：ETF 实测分红频率/权益登记日/申赎到账周期（§5.3 第 3 项）、直接持股批次台账（第 4 项）缺失 → **税务影响只能定性披露，不得定量、不得进绩效表**；若 Phase 5 试图用 `divTax` 固定比例刻画「减半→买回」的期限重置 → 判为**建模错误**（`bt_final.js:55` 结构上不支持）。

## 七、给主理人的结论摘要（按类型与置信度汇总）

| # | 结论 | 类型 / 置信度 |
| :-- | :--- | :--- |
| 1 | 现有引擎 `v·dy = u·DPS` 恒等式；合成路径沿用历史插值 dy **隐式假设 DPS 与股价同比例下跌**，若再显式削减 DPS 即**双重扣减**；必须 DPS 与价格分离 | 推断·高 / 判断·中 |
| 2 | 慢熊/通缩下分子（EPS·payout）与分母（P）反向运动，股息率方向**不定且强路径依赖**；A 与 B/C 的建模修正方向相反，须分路径报告、不得平均 | 推断·中 / 判断·中 |
| 3 | 本地实证：2015H2 价格仅跌 14.5~16.6%，TTM 股息率却涨 66.7~87.1%，纯分母效应仅解释约 17~20%，其余为 TTM 窗口/除息季节性伪变 → **股息率不是干净的外生现金流参数** | 事实·高 + 推断·中 |
| 4 | 「股息不计入」作为**基准口径是错误**（与价格指数不含股息叠加双重遗漏），但作为**下界压力口径应保留并重命名**；在 2016-01-28→03-03 窗口因除息空窗而局部近似成立 | 判断·高 / 推断·中 |
| 5 | 修正股息建模对 Phase 5 的方向性影响：A 使余量略增、触发更不易；B 含 DPS 削减则相反；C 不可预判。**均为二阶小量，不翻转「边界敏感」裁定，也不构成存废依据** | 推断·中 / 判断·高 |
| 6 | 主实现（ETF/场外基金）下减半/恢复**不改变投资者层面分红资格、除息日、持有期限与股息税**（财税〔2002〕128号/1998〕55号）；真实摩擦是申赎到账延迟与恢复时点不确定 | 事实·核对·中 + 判断·中 |
| 7 | 直接持股下减半**卖出即触发补税清算**、买回**重置持股期限**（财税〔2015〕101号，2015-09-08 施行）；v1.5 的 10% 固定比例税结构上无法刻画该路径依赖 | 事实·核对·中 + 判断·中 |
| 8 | 恢复时点不确定造成的股息 carry 净缺口：L=20~60 时账户层 **0.02~0.15pp**、L=∞ 约 **0.29~0.37pp/年**（解析近似、非绩效）；比价格侧机会成本小约一个数量级，**不具裁决力** | 推断·中 |
| 9 | ROE/收入/派息率/折价/资金流等风险信号**只能支撑 25% 静态参数**：性质（慢变量）、频率（滞后不可逐日复现）、维度（权益内相对权重）、既有出口（季度审阅）四重错配；写进第 5 条将违反第 4 条与铁律，并产生前视偏差、过拟合、信号-R 语义冲突、尾部恶化 | 判断·高 / 推断·高 |
| 10 | 行业侧保留意见①**准确、建议采纳**；但须先澄清 **0.48pp 为 CAGR pp/年、0.49pp 为回撤幅度 pp**，量纲不同不可比较；并补机制归因与「同比例缩放、不改变 75/25」边界 | 判断·高 |
| 11 | 主理人 6 条关键事实**全部核对无误**；仅补一处口径澄清（2.31/4.04/1.73pp 为插值日频均值，34 点等权为 2.3286/4.0588/1.7302）与一处机制补充（股息税卖出清算） | 事实·高 / 事实·中 |
| 12 | 3 条可检验命题（D1 建模约束 / D2 口径定性 / D3 缺口量级）均附成立、失效、数据不足判据 | 判断·中（待验证） |

**给主理人的一句话**：从分红现金流与税务维度看，**股息建模方式确实是「边界敏感」的独立来源，但它的量级是二阶的、方向在 A 与 B/C 之间相反、且数据基础薄弱，因此它支持的是「把股息口径写清楚、列入敏感性网格、在执行层如实披露」，而不支持据此对第 5 条存废下任何结论**；红利基本面风险信号继续维持其「仅定静态参数」的既有定性，不得跨过触发层边界。

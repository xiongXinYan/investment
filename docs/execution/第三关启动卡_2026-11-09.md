## 五、每周怎么做（4 步，约 3 分钟）

```bash
# 1) 取该周最后一个交易日收盘价（510300 / 515080），以及现金实际到账年利率
#    数据取不到就停下，不得估算、不得用上一周价格顶替

# 2) 记录一周
node tools/paper-ledger/gate3.js week --date 2026-11-13 --ph 4.124 --pd 1.563 --rate 1.30

# 3) 看状态（回撤 / 距 R / 偏离 / 待办）
node tools/paper-ledger/gate3.js status

# 4) 把 gate3_backup.json 导入台账，看「② 周度记录」与「⑤ 12 周判定」
```

季末（2026-12-31）当天先 `week` 记录收盘，再执行：

```bash
node tools/paper-ledger/gate3.js rebal --date 2026-12-31 --ph <收盘> --pd <收盘>
```

**两道自动守卫（不用你记，但被拦时要知道是什么）**

- 单腿价格相对上周变动超过 **25%** 会被拒绝，并打印「原价 → 新价」。这是拦小数点错位（`4.124 → 41.24`），不是拦行情；真遇到极端周，核对无误后加 `--confirm-outlier` 重跑。
- 已跨过季末但没记 `rebal`，`week` 会在写完后直接提示该执行的命令。2026-12-31 那一周的周五是元旦休市，不要等「周五提醒」——按 §四 的日历，那一周记 12-31 本身。

**每周除了三个数字，还要记一句人话**：这周有没有想改规则、想加仓减仓、有没有因为看盘影响做事。数字进 `gate3_state.json`，这句话进台账「④ 达 R 书面复核」或 `--note`。这一关真正要抓的是这句话，不是小数点。

## 六、无保护声明（须逐字读，读完再签）

> 本组合由 65% 现金 + 35% 权益构成，权益内部 75/25。它**没有任何尾部保护机制**：
> 没有止损、没有对冲、没有波动率目标、没有触发式减仓、没有黄金/债券/海外分散。
> 在人工构造的长期慢熊路径下，回撤可达 R 的 **1.17~1.41 倍**（v1.6 §1.3）。
> 「回撤到 R 就做一次书面复核」是**治理动作，不是风控动作**，其净值效应与完全不设此条**逐位恒等（0.000pp）**。
> 现金端是**薄缓冲**（历史实际收益 +0.4~1.3pp），不是安全垫。

## 七、什么情况算这一关失败（任一即止）

1. 为了「让记录好看」而补记、倒填、或编造某一周数据；
2. 在下跌中修改 E / 75/25 / R / 暂停再平衡，且事后用「情况特殊」解释；
3. 回撤达 R 但没有留下书面复核（或反之：没到 R 却虚构一次复核）；
4. 连续两周以上漏记，且无法用当日收盘价补齐（价格可补，**当时的情绪与冲动不可补**）。

第 4 条要区分清楚：**价格可以补，行为不能补。** 漏记的那一周如果在下跌，补上的价格是真的，但你当时想做什么已经无法重建——如实标注「该周未记录」，比补一个漂亮数字诚实。

## 八、这一关能证明什么、不能证明什么

**能证明**：规则能否被稳定执行；台账口径能否在真实价格下自洽；季末再平衡会不会被「同比例缩放」偷换；回撤靠近 R 时人会不会开始重新解释规则。

**不能证明**：收益可复现。12 周 ≈ 60 个交易日，样本长度连一个季度都不到；回撤大概率**到不了 20%**，第 5 条复核栏为空是**正常且诚实**的——空栏本身说明这 12 周没有覆盖到条款触发区。

**已知未建模项（本关同样不覆盖）**：ETF 分红到账、折溢价与 IOPV 失真、场外赎回到账在途、跨除息日耦合、人工下单出错。若 12 周内遇到分红，用 `week --cash-add <金额>` 记入现金并在周记里注明。

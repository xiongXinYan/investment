# 投资策略研究系统

一套**固定敞口指数配置**方案，以及支撑它的可复现研究工程。

不是择时策略：不判断估值分位、不数市场广度、不设止盈、不做暴跌加仓。风险预算一次前置于「可接受最大回撤 R」，此后不因市场状态改变敞口。

| 项 | 值 |
| :--- | :--- |
| 标的 | 沪深300（000300）+ 中证红利（000922），权益内 **75 / 25** |
| 回测区间 | 2010-01-04 ~ 2026-11-06（4,089 交易日，16.84 年） |
| 资金规模假设 | 50 万元 |
| 当前策略版本 | **v1.6**（`docs/strategy/投资策略规划_v1.6.md`，唯一权威规则文本） |
| 推荐参数档 | R=20% → 总敞口 **E=35%**，现金 65% |

## 一、当前正式策略

**六条规则**（完整文本与证据链见 `docs/strategy/投资策略规划_v1.6.md`，一页执行卡在其 §〇）：

1. 由可接受最大回撤 **R** 查表确定总权益敞口 **E**；
2. 权益内部沪深300 75% / 中证红利 25%（研究注释：25% 不承担尾部保护职能）；
3. **每 63 个交易日**按目标比例整表重置份额（不是阈值触发）；
4. 不做择时；
5. 账户回撤达 R 时做**一次书面复核**——**不改敞口、不改份额、不暂停再平衡**（v1.6 已删除原「减半」条款）；
6. 资金用途优先。

> **无保护声明（须逐字保留）**：本组合**没有任何尾部保护机制**。账户最大回撤由事前选定的静态敞口 E 单独决定，不由任何触发式动作调节。**R 是资金安排的输入参数，不是回撤上限保证。**人工构造的慢熊路径下，R=20%/E=35% 的账户回撤可达 **23.425%~28.211%（1.17~1.41 × R）**；R 在急跌型情景守得住（0.70~0.92 × R），在慢熊里守不住。不要因为本方案「有规则」而认为它「有风控」。

## 二、核心回测结果（唯一有效口径）

主口径：`75/25 ｜ 现金分段 3.0%/2.3%/1.3% ｜ 成本 费 5bp + 滑点 10bp ｜ 成交 T+1 ｜ 再平衡 q63 ｜ 股息 carry 计入`。

| R | E | 最大回撤 | 年化（252 口径） | 年化（日历口径） | 余量 R−MDD |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 15% | 25% | 12.173% | 3.079% | 2.965% | 2.827pp |
| **20%** | **35%** | **17.234%** | **3.327%** | **3.204%** | **2.766pp** |
| 25% | 45% | 22.102% | 3.527% | 3.396% | 2.898pp |
| 30% | 55% | 26.792% | 3.677% | 3.541% | 3.208pp |

**三个必须一起读的口径事实**（数字全部由 `src/metrics_v16.js` 从引擎实跑得出，见 `data/derived/metrics_v16.json`）：

1. **年化有两种口径，不得混用。** 上表「252 口径」用 `nav.length/252`，而 A 股实测 242.85 交易日/年，因此**系统性高估 0.11~0.14pp**；可比的时间加权收益是日历口径。**MDD 不受影响**（路径量），所以参数决策不变。
2. **口径极差有六种算法，不能只报一种。** 主口径下：单变量极差 **1.473pp**、单维+日历 2.315pp、全 160 格 2.395pp、全网格+日历 **2.692pp**。R→E 表要求「余量 ≥ 2.7pp」，对单维是 1.88~2.18 倍，**对全网格只有 1.03~1.19 倍——几乎没有冗余**。
3. **历史年化不是未来预期。** 现金端每变动 1pp，组合年化变动约 0.62pp，是全部假设里弹性最大的一项；指数估值、分红与真实执行成本都会改变结果。

R=20% 这一档在主口径下**触发 0 次**——但那是「恰好被一条历史路径避开」，不是「按构造不会触发」：现金利率 −1pp、前瞻利率用 1.3%、股息 carry 归零、q63→calQ，**任一处单独变动都足以触发 1 次**。

## 三、怎么验证

```bash
npm test              # 10 道闸门，约 1.5 秒。提交前唯一必需命令
npm run test:full     # 闸门 + 重算主回测/敏感性/压力 + 重算后指标/一致性/回归/指纹闭环
```

| 闸门 | 抓什么 | 失败意味着 |
| :--- | :--- | :--- |
| `src/data_audit.js` | 11 项数据检查（日期对齐、重复、跳变、股息重复计算） | 数据不可用，拒绝出数 |
| `config/verify_config.js` | 配置登记与代码 34 项断言 | 配置或代码有一份在说谎 |
| `src/metrics_v16.js` | 四档 R→E + 六种口径极差，唯一指标源 | 指标源与已发布值偏离 >0.0015 即拒绝写盘 |
| `tests/test_engine_invariants.js` | **46 项引擎不变量**：高水位/回撤自洽、无负现金、T+1 时序、重置后权重精确回 75/25、成本单调、重跑确定性 | 引擎路径不自洽 → 任何绩效数字都不可引用 |
| `tests/test_data_provenance.js` | 每份原始数据的来源证据等级、分红口径、行数区间、三方哈希一致 | 输入说不清出处，结论不可追溯 |
| `tests/test_report_consistency.js` | MD / HTML / README / 台账 与数据源逐位一致，且不得复用已撤销措辞 | 同一结论在多份文档里改到一半 |
| `tests/test_regression.js` | 17 个用例的整条净值序列（容差 1e-9） | 改动动了数字 |
| `tests/test_ledger_v16.js` | 纸面台账 80 条断言（浮点边界、空行守卫、备份校验） | 台账会算错数 |
| `tests/test_gate3.js` | 第三关 63 条断言（整手取整、成本、现金计提、再平衡、导出可被台账导入） | 12 周的记录会算错，且不可重建 |
| `src/manifest.js` | 回测指纹：config / data / 引擎 / 产物四组哈希 + commit | 报告与数据/配置已脱钩 |

不变量测试与溯源校验都带负向自测（`--negative` 与临时改坏数据验证），确保检查本身不是空转。

## 六、诚实的边界

- **工具层可得性不成立**：中证红利 000922 的场内 ETF 最早 2019-11-26 成立，2010~2019 无可交易工具；回测消费的是指数点位，隐含「全期可按收盘价成交两类工具」在工具层不成立。
- **两份指数序列的复权口径无原始凭证**：「不含股息」依据的是项目内部研究记录 + 引擎实现互证，不是文件自证。若日后换用全收益指数而未关闭股息 carry，全部年化数字会虚高。见 `data/metadata/datasets.json`。
- **成本与摩擦只覆盖一部分**：6 项无法用 bp 表达的摩擦（书面复核延迟、到账资金不可用窗口、跨季跨除息日耦合、ETF 历史缺席、折溢价与 IOPV 失真、人工执行出错）只登记、未建模。
- **样本只有一个**：全部结论来自 2010-2026 同一段历史；walk-forward 只有 4 折；配置倾斜的 bootstrap 区间仍跨零。

完整清单（每条带可复算的偏差量级）见 `docs/methodology/已知局限.md`。

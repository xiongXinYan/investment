# 投资策略规划（沪深300 · 从周期择时到单一常数敞口）

一套个人投资策略的完整设计与验证过程：v1.0 原始构想 → 审计发现结构性缺陷 → v1.1 重构 → v1.2 调整资产构成 → v1.3 依据修正证据做减法 → v1.4 取消双轨制 → v1.5 对最终方案本身做独立审计 → **v1.6 删除唯一残留的触发式敞口变更（第 5 条达 R 减半），并给 R→E 表加上口径余量约束**。

**标的范围**：沪深300、中证红利
**回测区间**：2010-01-04 至 2026-11-06（约 16.8 年，4,089 个交易日）
**资金规模假设**：50 万元
**当前版本**：`docs/strategy/投资策略规划_v1.6.md`

## 三个核心结论（第一、二轮，v1.4 口径）

**1. 择时层的增量是 0.00pp / 0.03pp，取决于股息率口径，都不显著**

| 口径 | v1.2 完整规则 | 同敞口常数混合 | 择时增量 |
| --- | ---: | ---: | ---: |
| 常数股息率 2.5%（v1.1~v1.3） | 3.41% / 20.6% | 3.41% | **0.00pp** |
| 真实逐年股息率（v1.4 主口径） | 3.35% / 20.81% | 3.33% | **0.03pp** |

block bootstrap（20 日块、1,000 次）95% 区间 **−1.69 ~ +1.67pp**（常数）/ **−1.57 ~ +1.59pp**（真实），正值比例约 52%。起点改为 2013 / 2016 / 2019，增量为 −0.60 / +0.30 / −1.30pp；3 个不重叠 5 年窗口为 −0.31 / +0.36 / −0.50pp；样本外 4 折 walk-forward **全部选中默认参数**。**没有统计证据表明择时层创造超额。**

**2. 风险由敞口决定，不由规则决定；风控线曾形同虚设**

固定敞口 30%→55%，年化只从 3.55% 到 4.01%（+0.46pp），最大回撤却从 13.74% 扩到 25.67%（+11.93pp）。构造的三条极端路径里，v1.2 的三级风控在 **2 条路径上 0 次触发**；2008 式慢熊下 v1.2 完整规则 −2.67% / 31.99%，反而差于「常数 40% + 达 R 减半」的 −0.66% / 27.21%。v1.4 只保留「达 R 减半一次」，并明确 **R 是触发线不是回撤上限**。

**3. 复杂信号可被更简单的东西替代，配置倾斜仍主要靠假设**

- **估值分**：接入四维估值分后年化 3.35%→4.27%（+0.97pp），但只把入场回撤阈值 ×1.2、不用任何估值数据，得到**完全相同的 4.27%**；bootstrap 区间 −0.68~+2.52pp 仍跨零。
- **广度 B**：NeoData 无「成分股站上 60 日均线比例」历史序列，S3 永久不可验证。
- **配置**：换成真实股息率后，红利权重 25%→41.9% 的增益从 0.44pp 降到 0.42pp；纯价格差异只剩 0.21pp。

## 第三轮补充结论（2026-11-07，v1.5 口径）

第三轮把火力转向**v1.4 最终方案本身**——因为它用「0.03pp 不显著」砍掉择时层，却保留了 70/30 相对单资产 +0.48pp 的配置倾斜而从未检验。审计完成后，团队更正输入并重新收口，把权益内配置从 70/30 调整为 **75/25（25% 单点、主动硬上限）**。

**1. 这条优化经得住检验，最初的「双重标准」质疑被否证**

| 检验 | 择时层（已否决） | 70/30 倾斜 |
| --- | --- | --- |
| bootstrap 95% 区间 | −1.57~+1.59pp | **−0.24~+1.13pp** |
| 正值比例 | 约 52% | **89.65%**（5 种块长 89.7~90.8%） |
| 4 起点 / 3 独立窗口 / 4 分段 | 符号反复翻转 | **全部为正、无翻转** |

+0.48pp 中价格差 0.27pp、股息率差 0.21pp；剔除 2020-05 后红利价格超额仍有 +0.29pp，两指数价格完全相同仍有 +0.21pp。全成本叠加后增益仍有 +0.44pp。**但回测只支持「有倾斜优于无倾斜」，不支持任何具体权重数字**：权重 0→100% 年化单调 3.30%→4.84%，三个相位段都单调。最终采用的 25% 同样不是优化结果，而是「增益方向稳健但统计不显著，叠加基本面恶化与相对折价收敛后取 v1.4 已授权区间 25%~35% 下沿」的保守参数取值。

**2. 真正的大漏洞在现金端，不在规则**

现金收益每变动 1pp，组合年化变动 **0.62pp**（大于配置倾斜全部 0.48pp），而 2.5% 常数覆盖 16.8 年未动，且最近两段低估回撤 0.29pp / 0.21pp。v1.5 改分段真实利率，前瞻按 1.0%~1.5% 做资金安排。

**3. R 减半条款在主口径下触发 0 次，但「按构造不会触发」的定性是错的**（本条第 3 句已被第四轮推翻，原样保留归档）

四个 R→E 档位在真实历史中触发 **0 次**（余量 1.29~4.36pp），因为 E 本就由「历史 MDD 略小于 R」反推。它的全部证据只有 3 条人工构造路径；且触发时是「暴跌后追跌减仓」，与「不做择时」潜在冲突。

> **第四轮更正（2026-11-08）**：v1.5 原文写「按构造不会触发、是结构性免疫」——**该判定错误**。在 160 个口径变体 × 4 档 R 的全检中，**现金利率 −1pp / 前瞻利率用 1.3% / 股息 carry 归零 / q63→calQ 四处各自独立**即足以使 R=20% 触发 1 次。正确表述是「**边界敏感、非结构性免疫**」。同时「0 次触发」**不等于「效应为 0」**，只等于「**不可评估（not estimable）**」。该条款已在 v1.6 删除（见下一节）。

**4. 口径与实现修正、以及一次汇总错误的更正**

季度再平衡原实现只调总敞口、资产间份额同比例缩放，红利权重无声漂到 36.9%（修正后 33.2%；75/25 下若不修会漂到 31.27%，修正后 27.88%），收益影响仅 0.00~0.01pp 但规则与实现不一致；v1.5 要求按目标比例重置两个资产的份额，禁止同比例缩放，并在周度记录新增「权益内红利占比」一栏。

**诚实披露**：Phase 1 汇总时曾误把一份不存在的「估值定价师维持 30%、改双条件」结论当作已回传，并据此做了第一次收口（30% 中枢 / 35% 硬上限）。该成员的真实结论方向相反（建议下调到 10~15%、动态分位门槛）。更正输入后由风险诊断师**重新收口，第一次结论全部作废**；v1.5、团队汇编报告与 HTML 报告均采用重新收口后的结论。

**5. 重新收口裁决：25% 单点，规则结构不动**

- **权重**：权益内 **沪深300 75% / 中证红利 25%**，25% 是单点目标、也是主动调整的硬上限，**不设任何触发式调整**；六条规则不增删、不引入新机制。25% 取自 v1.4 已授权区间下沿，属参数取值。
- **不采纳 10~15%**：估值定价师「+0.48pp 约 67% 来自已兑现的一次性相对重估」是归因假说；本地逐位复现了折价数据（PE 比 0.4116@2021-12-31 → 0.6698@2026-11-06、PB 比 0.4136 → 0.6542、息差峰值 369.7bp → 128.3bp），但样本外第 4 折（100% 红利 / 30% / 单资产 = 5.607% / 4.468% / 3.954%，正是折价收敛之后）、反事实 +0.29pp / 纯 carry +0.21pp、三段单调、全成本 +0.44pp 均不支持「重估已兑现 ⇒ 未来无超额」。用一次性归因推翻全部稳健性检验是另一种过拟合。
- **为何不维持 30%**：不是票数问题，而是新增了方向一致的风险信号——红利 ROE_TTM 10.48%→8.70%、收入同比连续三年负、隐含派息率比值 1.27→0.975、2026Q3 红利基金净流出 4.8%。同时删除 v1.4 用「怕行业集中」给 30% 兜底的理由：穿透后最重行业仅占总资产约 2.83%，即使 100% 红利也仅 9.64%，该约束从未成立。
- **明确拒绝 p20/p10 动态分位门槛**：属规则级估值择时、与规则 4 冲突；门槛强制度依赖（2010–2019 息差 ≥1.5pp 仅 25% 时间满足，2020 后 92.9% 满足）；且 2026-09-30 季末 152bp 尚 PASS、11-06 现货 128bp 即 FAIL，季末/现货口径切换就能翻转信号。
- **风险信号 ≠ 规则输入**：估值分位、PE/PB 比、股息率差、资金流向**一律移出触发条件**，仅作研究信号，可用于定期审阅时确定静态参数（30%→25% 正是这样得出的），不得作为自动触发状态机输入。两位成员对同一指数 000922 同一时点给出的估值分位口径互相矛盾，方向同向但动作相反，不可作规则依据。

## 第四轮结论（2026-11-08，v1.6 口径）

第四轮只做一件事：**决定 v1.5 第 5 条「达 R 减半一次」的存废，并据此重构尾部保护表述**。不扩资产类别、不动 75/25、不动「不做择时」。

**1. 主口径下条款触发 0 次，净效应不可评估**

三条路径逐位恒等：`(ii) 保留` ≡ `(i) 无条款` ≡ `(iii) 季度恢复`，`maxAbsDiff = 0`。`(ii)−(i)` = 0.000pp/年、0.000pp 回撤；`(iv) 全期静态 eq=0.20` 为 2.936% / 4.124% / MDD 9.746%，`(iv)−(i)` = −0.497pp/年、−9.945pp 回撤，`(ii)−(iv)` 恰为镜像。**一个从未动作的条款，其收益不存在可观测量。** 按预注册纪律：不给 p 值、不给置信区间、不给功效数值，只写「不可评估」。

**2. 但「按构造不触发」是错的 —— 边界敏感、非结构性免疫**

160 个口径变体 × 4 档 R 全检：现金利率 −1pp、前瞻利率改用 1.3%、股息 carry 归零、q63→calQ，**每一处单独变动都足以让 R=20% 触发 1 次**。所以条款不是「构造上不可能触发」，而是「恰好被主口径下的历史路径避开」。这是本轮最重要的定性更正。

**3. 真正的量化发现：v1.5 的 R→E 表只有「拟合残差」当安全垫**

| R | v1.5 的 E | v1.5 余量（R−MDD） | 与主口径单维极差 1.473pp 之比 |
| :-- | :-- | :-- | :-- |
| 15% | 30% | 0.272pp | **0.18×** |
| 20% | 40% | 0.309pp | **0.21×** |
| 25% | 50% | 0.531pp | **0.36×** |
| 30% | 55% | 3.208pp | 2.18× |

**换一个同样合理的口径，回撤就变动 1.473pp —— 是 R=20% 余量 0.309pp 的 4.77 倍。** 这意味着 R=15/20/25% 三档上，R 不是「约束」，而是「恰好被一条历史路径满足」。v1.6 因此给 R→E 表加上约束：**余量 ≥ 2.7pp**，取满足该约束的最大 5% 整数档敞口 → **15→25% / 20→35% / 25→45% / 30→55%**，年化代价 −0.130 / −0.106 / −0.081 / 0 pp（约 0.1pp/年）。

> **本节曾用 1.301pp 作为口径极差（2.7pp = 2.13×，宣称「约 2 倍」），该基准已更正**：1.301pp 是**账户层简化口径**（现金不计息/无成本/不含股息）下的**日历单维**差，不是主口径、也不覆盖其余五维。主口径的六种算法见 v1.6 §4.2：单维 **1.473pp**、单维+日历 **2.315pp**、全 160 格 **2.395pp**、全网格+日历 **2.692pp**。因此 2.7pp 余量的真实倍数是 **1.88~2.18×（对单维）** 与 **1.03~1.19×（对全网格）**——**后者几乎没有冗余**，「约 2 倍」的说法已撤销。

**4. 补上了一个证据缺口：v1.6 推荐的 E 有三档此前从未做过压力检验**

Phase 5 的压力路径网格绑定 `R2EQ = [[15,30],[20,40],[25,50],[30,55]]`（v1.5 旧表），与 v1.6 的 25/35/45/55 **交集只有 55%**。`src/phase6_stress_v16.js` 补跑（先逐位复现原 36 单元、`maxAbsDiff = 0`），结果：**R 在急跌型情景守得住（0.70~0.92 × R），在慢熊里守不住（1.17~1.41 × R）；最高档 E=55%/R=30% 达 2.16~2.55 倍，最坏档物理越界**。初稿「1.3~1.5 倍」的表述把 E=40% 的数字挂到了 E=55% 的句子上，已更正。

**5. 裁决：删除触发式减半，保留书面复核 —— 理由不是「回测证明无效」**

三条独立理由：**① 不可验证性**（16.8 年从未动作，收益无法验证；一旦动作即「暴跌后追跌减仓」，与不做择时结构性冲突）；**② 规则一致性**（v1.5 自己已写它「不构成尾部保护」却留在规则正文，制造「组合具备风控」的暗示）；**③ 执行与治理成本**（辅助、**不单独成立**：成交事件 66→64、直接成本 ≤0.2% 账户、状态变量 ~12→3、消除第 3 与第 5 条的文档冲突）。

保留的书面复核**不是风控**：不改 E、不改份额、不改 75/25、不暂停再平衡，只触发一次四项内容的书面复核，结论仅用于下一次定期审阅。它是**把行为约束留下、把敞口变更去掉**。

**6. 一次数据质量事故的如实披露**

压力路径 `hi × R=30%`（eq=55%）名义跌幅 **−105%**，越过权益 −100% 物理下限，`ln(1+drop)` 无实数解 → nav 崩溃 → 绩效函数的 MDD 循环**静默返回 0 的假象值**。处置：判「不可评估」并留空 7 个字段，**不截断到 −95%、不外推、不伪造 0**；并在 `met()` 加非有限值守卫（NaN/Infinity 直接抛错）。重跑后 36 单元 / 已评估 35 / 不可评估 1 / `NaN`·`Infinity` 残留 0 / 双零假象 0。

**7. C 表口径敏感性实际跑了 808 单元，不是任务书的 1,152**

四个独立子矩阵（640 + 96 + 36 + 36），而非单一全笛卡尔积 —— 为**避免「人工构造情景 × 真实成本档」的语义污染单元**。所有维度、6 维标签、分层分布无遗漏；主理人裁定接受，不补齐 1,152。

`src/bt_engine.js` 头部写着「回测引擎 v5：同步 v1.2 规则」，而当前策略是 v1.6。新增 `docs/methodology/ENGINES.md` 权威登记表，并给 `src/bt_engine.js` 加了顶部横幅。

## 已知局限

- **广度数据永久不可得**：S3 的 B≤25% 无法历史验证；估值层用的是 34 个半年度观测点线性插值，非日度全量。
- **仍未进回测引擎**：五类资产组合、倾斜规则、核心仓周期边界再平衡、高估减仓（v1.4 起均已从方案中删除）。
- **口径与假设**：成交按收盘价判断；已量化 T+1 成交代价（回撤 +1.09pp，75/25 口径下 0.927pp）。股息税按直接持股口径建模（ETF 实现下不重复计）。现金利率为三段式年度近似，非逐日实测货基净值；前瞻 1.3% 是情景假设。滚动 TTM 股息率作为未来一年收益仍是近似。
- **极端路径与反事实均为人工构造**，不代表任何真实市场情形。**v1.5 原文「R 减半条款按构造不会触发」判定错误，v1.6 已撤回**：条款在主口径下触发 0 次，但「边界敏感、非结构性免疫」，四处口径各自动变动一处即可触发 1 次。**「0 次触发」只等于「不可评估」，不等于「效应为 0」。**
- **工具可得性不成立（幸存者偏差，非摩擦）**：中证红利 `000922` 的场内 ETF 最早成立于 **2019-11-26**，2010~2019 无可交易对应工具。回测消费的是指数点位序列，隐含「全期可按收盘价成交两类工具」在**工具层不成立**。这是定性局限，不改写任何绩效数字。
- **标的口径陷阱**：`510880` 跟踪**上证红利 `000015.SH`，不是本方案 `000922.SH`**。运维须写死「基金代码 ＋ 跟踪指数代码 ＋ 快照日」三元组，禁止按「红利 ETF」字面选品。
- **6 项未建模执行摩擦**（逐项披露，不进引擎）：① 人工书面复核延迟（`reviewLagDays=20` 是建模假设非实测）② 到账资金不可用窗口（赎回款 T+4~T+7）③ 恢复日跨季跨除息日耦合 ④ 000922 ETF 历史缺席（幸存者偏差）⑤ 折溢价方向性与 IOPV 失真 ⑥ 台账与人工执行出错概率。
- **成本科目必须分离**：`slippage` / `premiumShock` 属**价格偏移**，`market impact` 属**占 ADV 比例**，科目不同、禁止叠加。「10 万元冲击成本基本可忽略」须补两条限定：工具可得性不成立、冲击成本 ≠ 全部执行摩擦。
- **三个 T+1 必须拆开**：回测 `execLag=1` / 场内交易制度 T+1 / 场外申赎确认与到账（赎回款 T+4~T+7）。E3 约束式：`effectiveLockDays ≥ 20 + settleLagDays + 1(申购确认) + (reviewLagDays − 20 超额部分)`，场外约 24~28+ 交易日。v1.6 因已删除第 5 条，E3 转为备查。
- **口径极差大于名义余量**：v1.5 R→E 表在 R=15/20/25% 三档的余量（0.272 / 0.309 / 0.531pp）**全部小于主口径单维极差 1.473pp**（倍数 0.18× / 0.21× / 0.36×）。这是 v1.6 加「余量 ≥2.7pp」约束的唯一原因，也是「把拟合残差当安全垫」的直接证据。**六种极差算法的完整对照见 v1.6 §4.2**：单维 1.473pp / 单维+日历 2.315pp / 全 160 格 2.395pp / 全网格+日历 2.692pp。2.7pp 余量对前者是 1.88~2.18 倍，**对后者只有 1.03~1.19 倍**。
- **R 会被突破多少（本轮补齐）**：压力路径显示，v1.6 推荐参数（R=20%/E=35%）在人工构造慢熊下 MDD 达 R 的 **1.17~1.41 倍**，在急跌型情景为 0.70~0.92 倍（守得住）；最高档 R=30%/E=55% 达 **2.16~2.55 倍**，最坏档名义跌幅 −105% **物理越界不可计算**。这三档 E（25/35/45）此前从未做过压力检验——Phase 5 网格绑定的是 v1.5 旧表，已由 `src/phase6_stress_v16.js` 补跑（先逐位复现原 36 单元、`maxAbsDiff=0`）。
- **样本与显著性**：全部结论来自同一样本；walk-forward 只有 4 折；配置倾斜的 bootstrap 95% 区间仍跨零，结论是「证据强度远高于择时层」而非「已证明显著为正」。
- **相对重估是归因假说、双向证据均在案**：估值定价师主张 +0.48pp 约 67% 来自已兑现的一次性重估、建议降到 10~15%，本地逐位复现了折价与息差数据；但样本外第 4 折、反事实与全成本检验不支持由该归因推翻全部稳健性结论，故不采纳。见 v1.5 第 4.4 节与 HTML 报告第 ⑥ 节。
- **权重 25% 不由回测给出**：回测只支持「有倾斜优于无倾斜」，也不支持任何具体数字；25% 是授权区间下沿 + 风险信号下的保守取值，不是优化结果。删除了 v1.4 用「怕行业集中」给 30% 兜底的理由（约束从未成立）。**75/25 与第 5 条存废相互独立，25% 不承担尾部保护职能**：2020-03 急性段测算显示，权益内全部调权自由度对账户层缓冲仅值 0.01~0.49pp，同期总敞口 E 变动值 3.22~8.70pp，量级差 3~176 倍。
- **估值分位口径冲突未裁定**：两位成员取数口径不同，不裁定对错，判定该类输入不可作规则化触发条件，仅可用于定期审阅定静态参数。
- **一个数据质量事故已如实登记**：压力路径 `hi × R=30%`（eq=55%）名义跌幅 −105%，越过权益 −100% 物理下限，`ln(1+drop)` 无实数解 → nav 崩溃 → MDD 循环静默返回 0 的假象。已判「不可评估」并留空 7 个字段，**不截断、不外推、不伪造 0**；`met()` 已加非有限值守卫。
- **C 表实跑 808 单元而非 1,152**：四个独立子矩阵（640+96+36+36），非单一全笛卡尔积，为避开「人工构造情景 × 真实成本档」的语义污染单元；维度与 6 维标签无遗漏。
- **年化口径高估 0.11~0.14pp（第五轮审计 D1）**：全部已发布「年化」为 252 交易日口径，A 股实测 242.85 交易日/年。日历年化值：R=20%/E=35% 为 3.204%（非 3.327%）、E=40% 为 3.306%（非 3.433%）。MDD 不受影响，故参数决策不变；但引用绝对收益水平时必须标口径。
- **股息率序列存在插值前视（第五轮审计 D2）**：半年度 34 点线性插值，区间内每日用到下一个观测点，最大偏离 2.154pp。无前视后 CAGR −0.006pp / MDD +0.057pp，R=20% 档余量降到 2.709pp（阈值 2.7pp，只差 0.009pp）。已提供开关，下一版切换。
- **红利倾斜降低回撤这件事，全样本不成立（第五轮审计 E1）**：纯权益把红利从 0% 加到 100%，MDD 只从 46.27% 降到 45.66%（−0.61pp），年化却涨 3.64pp。全样本 MDD 由 2015 共同崩盘决定；防御性只在 2019-2026 风格分化段出现。v1.6 §2 已写「25% 不承担尾部保护职能」（正确），本审计补的是更强的一句：**连普通回撤也不降，倾斜的收益全部来自收益端**。权重保留，理由应改为「不押注单一因子」。
- **季度再平衡是双面的（第五轮审计 E2）**：慢熊段（2021-02~2024-09）季度比年度 MDD 差 +0.81pp、收益差 0.15pp/年；全样本季度 MDD 最低（17.234% vs 年度 19.003%）。两个效应方向相反、量级都 <1pp。
- **初始建仓未计交易成本**：一次性约 0.05%（≈0.003pp/年）未计入基线；`src/execution_simulator.js` 的实盘口径已计入。整手约束在 50 万账户下影响可忽略（CAGR −0.005pp、MDD +0.06pp）。
- **两份价格数据无溯源字段**：无 source / fetched / 复权口径，仅有 sha256 快照。出处需人工确认后补写，不代填。
- **第三关仅剩一项**：12 周纸面执行未开始，是正式投入前唯一剩余关卡。

# 投资策略规划（沪深300 周期择时）

一套个人投资策略的完整设计与验证过程：从 v1.0 的原始构想，到审计发现结构性缺陷，再到 v1.1 重构，最后 v1.2 依据回测结果调整资产构成。

**标的范围**：沪深300、中证红利、中证500增强、科创50、行业 ETF
**回测区间**：2010-01 至 2026-11（约 16.8 年，4089 个交易日）
**资金规模假设**：50 万元

## 三个核心结论

**1. v1.0 的仓位设计在数学上不成立**

90% 权益上限沿压力路径推演出约 46% 的隐含回撤，而其声明的风险预算是 25–30%。更关键的是，它自己设定的账户回撤警戒线会先于 S3 触发——S3、S4 的仓位从来没有机会被执行。同时，滚动估值窗口使同样 13.6 倍 PE 在 2024 年读作"5% 分位"、在 2026 年读作"60% 分位"，指数跌了 19% 而指标仍判断"不便宜"。

**2. 择时层没有创造可测量的超额**

把全部卖出规则接入回测后：

| 对照 | 年化 | 最大回撤 |
| --- | ---: | ---: |
| v1.1 策略（完整规则） | 3.53% | 20.6% |
| 同敞口 44% 常数混合（仅季度再平衡） | 3.41% | 20.8% |
| 沪深300 满仓持有 | 2.72% | 43.2% |

差 0.12 个百分点，在噪声范围内。更换四组股权风险溢价假设重算，增量在 −0.09pp 到 +0.12pp 之间且方向不一致。原因在于"越跌越买"与"季度再平衡"在数学上等价。

**因此这套规则的定位是行为约束工具，而非收益增强工具**——它的价值是一张在暴跌时敢下手的书面授权。

**3. 资产选择的影响约是规则微调的 20 倍**

同一套规则，标的换成中证红利后年化从 3.53% 升至 4.85%（+1.3pp）。v1.2 据此把红利占权益比重从 25% 提到 41.9%，中证500＋科创50 从 28.2% 压到 12.9%，最坏路径回撤同步从 28.8% 降至 27.1%。

## 已知局限

- 回测仅使用**价格序列**，未接入估值分与广度条件，实际触发次数应少于回测的 3 次
- 中证500、科创50、行业 ETF 无对应序列，按沪深300 等价处理，v1.2 的收益改善是**保守估计**
- 样本仅 3 个周期，起点落在 2010 年高位，红利因子在该区间处于有利期
- 无分红、无费用的逐年实测，股息率取长期中枢而非实际值
- **未做**样本外验证与 12 周纸面执行（第三关）

## 文件说明

**策略文档**：`投资策略规划_v1.0/v1.1/v1.2.md`
**分析报告**：`策略审计报告_v1.0_*.html`、`回测报告_*.html`、`配置调整报告_v1.2.html`

**数据**（2010–2026 日线，来自东方财富公开接口）
- `hs300_daily_2010_2026.json`
- `csi_dividend_2010_2026.json`

**回测引擎与构建脚本**
- `bt_engine.js` — 回测引擎，含买入状态机、预算池、止盈/移动退出/时间退出
- `bt_data.js` → `bt_data.json` — 生成报告数据包
- `bt_report.js` — 渲染回测报告 HTML
- `alloc_data.js` / `alloc_report.js` — 配置敏感性分析与报告渲染

重新生成报告：

```bash
node bt_data.js      # 输出 bt_data.json
node bt_report.js    # 渲染 回测报告_卖出规则_2026-11-06.html
node alloc_data.js   # 输出 alloc_data.json
node alloc_report.js # 渲染 配置调整报告_v1.2.html
```
